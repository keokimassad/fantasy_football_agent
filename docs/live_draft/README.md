# Sanitized Live-Draft Artifacts

This directory contains public, derived artifacts from live-draft validation.

The raw production `data/draft_state.json` and `data/draft_logs/*.jsonl` remain ignored and private. Raw telemetry can contain copied Yahoo chat/usernames and embeds complete source snapshots for reproducibility. Publishing a sanitized derivative preserves portfolio/audit value without turning ephemeral runtime files into tracked public state.

`2026-final-state.json` contains the completed 150-pick board from the September 7, 2026 Yahoo draft with participant names, chat text, raw Yahoo input, league name, source datasets, and Yahoo player IDs removed.
